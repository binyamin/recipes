# Feature List

Focus on:

- Fast entry
- Clean reading
- Simple organization
- Zero friction

## Must Have

- List recipes
  - click to open recipe
  - empty state
- View recipe
  - schema
    - title
    - ingredients list (bulleted)
    - steps list (numbered)
    - created date
  - Edit button
  - Delete button
- Create recipe
  - list builder (for steps & ingredients)
    - add item (text entry + button)
    - remove item
    - edit item
  - client-side validation
- Edit recipe
  - same UI as "create"
  - pre-fill existing data
- Store recipes
  - Persist recipes in localStorage
  - Seed starter recipes on first load

## Nice to Have

- Print mode (css `@print`)
- Recipe Tags
  - Tag list page
  - List recipes by tag
  - View tags on recipe list page
  - View tags on recipe detail page
  - CRUD tags on recipe form page
- Grocery Mode
  - Combine ingredients from selected recipes into one list
  - printing?
  - checklist

## Won't Have

- UI tests
- Nutrition data
- Units math
- Ratings or comments
- Images
- User accounts
- Cloud Sync
